**Rule:** never reuse an old ID with a new meaning. Prefer `map_to_new` / compensation / legacy_readonly.

## Current → V2 strategy

### Items (~1008 → 170)
| Action | When |
|--------|------|
| `map_to_new` | Clear semantic match (e.g. `wheat`→`wheat`, `oil`→`crude_oil`, `gas`→`natural_gas`, `wood`→`softwood`, `fabric_flax`→`woven_fabric`) |
| `convert_to_compensation` | Player holds stock of removed SKU: cash credit = mid corridor × qty × 0.85 |
| `legacy_readonly` | Unknown/ambiguous IDs remain in inventory blob but cannot be produced/sold until compensated |
| `remove_only_if_unused` | Generator-only orphans (`bee*`) with zero world references |

Grade clones (`*_std`, `*_prem`, `*_ufa`, …) collapse into **batch quality 1–5** on the base V2 ID (no separate SKU).

### Buildings (~110 → ~90 extract+factory+logistics)
| Action | When |
|--------|------|
| Keep ID | Building still exists in V2 with same role (`mine`, `apiary`, `bakery`, …) |
| `map_to_new` | Old type → new type (`farm`→`grain_farm` / `crop_farm` by recipe; `chem_plant`→`chemical_plant`; `steel_mill`→`steel_plant`) |
| Compensate | Player building with no V2 role: refund `build_cost` × 0.9, demolish instance |

Logistics kept: `warehouse`, `garage`, `cold_storage`, `port_terminal`, `rail_depot`.

### Recipes (~1730 → ~200)
All V1 recipe IDs become inactive. Researched flags: map by output+building when possible; else refund research_cost.

### Shops (26 → 14)
Map overlapping retail types into the 14 formats; leases convert `shop_type` via table; invalid item_id on shelf → compensate stock.

## Save migration (copy only — never live VPS DB)

1. Snapshot SQLite → `data/saves/pre_v2_*.db`.
2. Load world JSON blob; rewrite inventories/buildings/shops/orders/contracts.
3. Set `world.catalog_version = 2`.
4. Re-open engine with V2 catalog; reject clients with incompatible catalog expectation.
5. Rollback: restore snapshot + set loader to legacy `data/legacy_v1/`.

## Stop conditions

Do **not** delete legacy files until Phase F green.  
Do **not** deploy V2 if e2e chains or migration on a **copy** fail.
