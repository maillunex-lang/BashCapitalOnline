# BashCapital

Онлайн экономическая стратегия в духе Capitalism Lab по Республике Башкортостан.

- **Клиент:** Godot 4 (`client/`) + web-превью UI (`web/`)
- **Сервер:** Go authoritative sim (`server/`)
- **Данные:** рецепты/города/здания (`data/`)
- **Время:** 1 игровой месяц = 24 реальных часа, **тик = 1 реальный час = 1/24 месяца**
- **Города (сейчас):** Уфа, Белорецк, Стерлитамак · 2.5D сетка на город
- **Этапы разработки для AI:** [`roadmap/STAGES.md`](./roadmap/STAGES.md)

## Запуск за 2 минуты (поиграть)

```bash
# 1) API (автотик каждые 30с в -dev)
cd server && go run ./cmd/server -data ../data -dev -addr :8080

# 2) Web UI — другой терминал
cd web && python3 -m http.server 8090 --bind 127.0.0.1
```

Откройте **http://127.0.0.1:8090/** → **Кабинет** → название + отрасль → **Открыть фирму** → выберите здание в каталоге → «Выбрать город и участок» → карта → подтвердить.

Чистый мир (если старый сейв мешает): `rm -f data/saves/bashcapital.db` и перезапуск сервера.

### Флаги сервера

- `-dev` — автотик каждые 30 секунд
- без `-dev` — тик раз в 1 час (`-tick-hours 1`)
- `-tick-hours 0` — только ручной `POST /api/tick`

### Дороги и стройка

- В городе есть стартовая дорожная сеть (крест от центра).
- Если строите **не у дороги**, сервер **автоматически прокладывает путь** до ближайшей дороги **за ваш счёт** (1500 ₽/клетка).
- Магазины имеют **зону охвата** (2–4 клетки): дальние кварталы сами не едут.

### Ресурсы / залежи

- На окраине генерируются **залежи** (руда, нефть, песок, кварц, лес, лён, молоко/пастбища, вишня, химия) по профилю города.
- Шахта / карьер / скважина / лесозаготовка / ферма ставятся **на клетку с нужной залежью**.
- Запас **конечный**: добыча списывает amount; после исчерпания залежь **пропадает и появляется в другом месте** того же города.
- Раз в игровой месяц возможна находка новой залежи геологами.

API: `http://127.0.0.1:8080`

- `GET /api/catalog` — справочники
- `GET /api/world` — состояние мира
- `POST /api/register` — `{ "name", "industry": "dairy|food|furniture|apparel|steel|oil" }`
- `POST /api/action/...` + заголовок `X-Firm-Id`
- `POST /api/tick` — форс-тик
- `WS /ws` — события тика

## Web-превью UI

```bash
# сервер уже на :8080
cd web && python3 -m http.server 8090 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8090` — карта города, рейтинг, стройка, аренда магазинов, арт зданий/товаров.

## Godot-клиент

1. Откройте папку `client/` в **Godot 4.3+**
2. Запустите сцену `scenes/main.tscn`
3. Укажите URL сервера и создайте фирму

Интерфейс: фон Башкортостана, логотип, изометрическая карта, боковая панель действий, рейтинг капитала, журнал тиков.

## Рецепты (MVP)

- молоко + бутылка (песок+кварц) → молоко в бутылке  
- молоко + вишня + бутылка → вишнёво-молочный напиток (R&D)  
- лён → ткань; дерево+химия → ДСП; ткань+ДСП → мебель  
- руда → сталь → металлоизделия  

## Графика (Godot / web-превью)

В настройках: **Низкое / Среднее / Высокое / Ультра**.

| Уровень | Что даёт |
|---------|----------|
| Низкое | 30 FPS, без MSAA, без амбиенса |
| Среднее | тени тайлов, редкие деревья |
| Высокое | машины на дорогах, больше деталей |
| Ультра | шейдер color-grade, колыхание деревьев, плотный трафик |

Игра стартует в **fullscreen**, UI в **safe-area** (вырез камеры / notch).

## Подписка и ИИ-заместитель

**ЮKassa (live):** задайте `YOOKASSA_SHOP_ID` + `YOOKASSA_SECRET_KEY`, webhook gate `YOOKASSA_WEBHOOK_SECRET` (или `YOOKASSA_SECRET`), опционально `PUBLIC_API_URL` / `PAYMENT_RETURN_URL`.

- `POST /api/payment/create` `{ "months": 1 }` → `confirmation_url` (redirect на ЮKassa)
- `POST /api/payment/webhook/yookassa` — уведомление; в live статус перепроверяется через API
- `GET /api/payment/mock-pay?id=…` — **только** `-dev` или `ALLOW_MOCK_PAY=1`

Dev без ключей: кнопка «Списать с кассы» / `POST /api/action/subscribe`.

- `POST /api/action/hire_deputy` `{ "name": "..." }`
- `POST /api/action/set_deputy_tasks` `{ "tasks": ["procure_inputs","restock","price_retail","sell_excess","research","auto_contracts"] }`

На каждом тике заместитель выполняет выданные задания: ищет поставщиков, пополняет магазины, ставит цены, сдаёт излишки, исследует рецепты, заключает контракты.
